Selected cell

Tips

With no brush, clicking a cell selects it for editing. Right-click a cell to copy its tile into the brush (eyedropper). A multi-tile brush stamps the whole block. Red tiles in the sheet have pixels but the map never shows them, so paint them in where they belong. Some red tiles are drawn by the game's code instead of the map (score digits, for example), so those are fine as they are. An orange corner on a cell means it differs from the ROM's map. Saving writes the map .bin; Build frames / build.bat put maps that have a ROM address back into the ROM in place.
